# GymApp

Личный дневник тренировок для Android на React Native и Expo. Работает
офлайн, все данные хранятся на телефоне в SQLite.

## Зачем

Чтобы во время тренировки быстро записывать подходы, а потом видеть, что,
когда и с каким усилием было сделано. Без аккаунтов, облака и рекламы.
Данные выгружаются одним JSON, который удобно анализировать в pandas.

## Что умеет

- **Тренировка с нуля.** Упражнения добавляются по ходу. Имя собирается
  автоматически по главным мышцам («Грудь + Трицепс») и пересчитывается
  с каждым новым упражнением. Шаблоны есть, но они вторичны: тренировку
  можно сохранить как шаблон уже после неё.
- **RIR вместо секундомера.** У каждого подхода отмечается, сколько
  повторов осталось в запасе: 0–5 или «не дотянул». Значение выбирается
  горизонтальным барабаном. Если нужен прежний режим с секундомером, его
  можно включить в настройках. Статические упражнения меряются временем,
  до слома формы.
- **Настоящая нагрузка.** Вводится то, что написано на снаряде, а
  приложение пересчитывает: пара гантелей удваивает вес, к упражнениям с
  собственным весом прибавляется вес тела.
- **Упражнения и мышцы.** У каждого упражнения есть главные и вторичные
  мышцы и снаряд. Поиск идёт и по названию, и по этим тегам на обоих
  языках.
- **История и календарь.** Месяц с отмеченными днями, разбор каждой
  тренировки: подходы, отдых, паузы, заметки.
- **Бэкап.** Экспорт и импорт всей базы одним JSON-файлом.
- **Два языка**: английский и русский.

## Как устроено

```
src/app/         экраны (expo-router, вкладки): календарь, тренировка,
                 история, шаблоны, упражнения, настройки
src/components/  барабан RIR, свайп-строки, перетаскивание, формы, шторки
src/db/          SQLite (expo-sqlite): схема и миграции, запросы, бэкап
src/lib/         RIR, расчёт нагрузки, автоимя тренировки, теги, i18n, тема
```

- **Схема версионируется** в `src/db/migrations.ts`. Старые данные
  переносятся при обновлении, а бэкапы, снятые до смены схемы, тоже
  импортируются.
- **Названия мышц и снарядов хранятся в базе по-английски** и переводятся
  только при показе. Поэтому смена языка не ломает поиск и старые имена
  тренировок.
- **Без `react-native-reanimated`**, чтобы приложение запускалось в Expo
  Go. Анимации и жесты сделаны на `Animated` и
  `react-native-gesture-handler`, а `.npmrc` не даёт npm подтянуть
  reanimated как peer-зависимость.

## Запуск

```
npm install
npx expo start          # Expo Go на телефоне
npm run android         # нативная сборка (нужен Android SDK)
```
